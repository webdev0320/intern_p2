✅ Steps to Update & Deploy Portfolio

🔹 1. Make your changes in code
		(Edit your files in VS Code)

🔹 2. Run the following commands in terminal:
		git add .
		git commit -m "updation in sidebar"
		git push origin talha 
	
		npm run build
		npm run deploy
🔹 3. Build the updated project
		npm run build

🔹 4. Deploy to GitHub Pages (using gh branch)
		npm run deploy


pull to github 
		
	# switch to your branch
		git checkout talha

	# get latest changes from remote
		git fetch origin

	# merge main into talha
		git merge origin/main
